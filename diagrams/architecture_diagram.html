Calls Services
Services

🔧 PartDetectionService

  • Image → multipart POST to FastAPI
  • Parses YOLO bounding boxes + classes
  • Confidence threshold filtering (≥60%)
  • Writes scan results → Supabase DB

📊 MarketplaceService

  • Unified CRUD for products, orders, cart
  • Role-based data access (RLS)
  • Atomic stock decrement via Postgres RPC
  • FCM token management & notifications

🏎️ SensorFusionService

  • 1-D Kalman Filter (GPS + IMU fusion)
  • Prediction: IMU accel → speed delta @ 50Hz
  • Correction: GPS speed → Kalman update @ 1-10Hz
  • Braking mode (sign inversion)

🔌 OBD WiFi Service

  • TCP socket → ELM327 adapter (192.168.0.10)
  • PID 010D (vehicle speed) polling
  • AT command initialization sequence
  • Hex response parsing → km/h

📈 PerformanceRunService

  • Test orchestration (countdown, timing)
  • Speed milestone detection (0-60, 0-100)
  • ¼-mile distance via trapezoidal integration
  • Results persistence → Supabase
HTTP / SDK
AI Backend

🤖 FastAPI Server Python 3.11

  • POST /predict — YOLO11 inference
  • Model: car_parts_large_v1.pt (YOLO11-L)
  • Returns: class, confidence, bounding box
  • CORS enabled for Flutter client

📦 Model Pipeline

  • Dataset: Custom car parts (Kaggle)
  • Training: Google Colab (YOLO11 Large)
  • Export: PyTorch → .pt weight file
  • Inference: Ultralytics predict API
